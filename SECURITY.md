# Security Policy

## Reporting a vulnerability

Please do not publish details of a suspected security vulnerability in a public issue before the maintainer has had a chance to review it. Contact the repository maintainer privately through the contact method configured on the GitHub repository.

Do not include private files, credentials, access tokens, or other sensitive data in a report.

## Safety notes

FileMind is a local file utility, not a backup system. Review organization previews and keep independent backups of important files. The project aims to avoid following symbolic links and overwriting existing destination files.
