# Changelog

## 2.0.0

- Added the `python -m filemind` entry point.
- Added recursive duplicate detection using SHA-256.
- Added terminal progress feedback to scan, largest-file, duplicate, and report operations.
- Improved no-overwrite behavior for organization moves.
- Expanded file extension categories.
- Added development, safety, and contribution documentation.

## 1.0.0

- Initial FileMind CLI with scan, largest, duplicates, search, organize, and JSON report commands.
